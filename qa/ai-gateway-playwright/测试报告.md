## 复现与重跑

```bash
cd qa/ai-gateway-playwright
npm install
cp .env.example .env   # 填被测地址与管理员密码
npm test
npx playwright show-report
```

单独重跑某个功能：

```bash
npx playwright test scripts/内部用户管理.spec.js
```

浏览器使用 Playwright 自带 chromium 时设置 `AIG_BROWSER=chromium`。需要录像时先执行 `npx playwright install ffmpeg` 再设 `AIG_VIDEO=on`。
