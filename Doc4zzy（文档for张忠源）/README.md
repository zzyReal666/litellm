## 使用说明

- 交付类文档（Word/PDF）与 Markdown 源文件放在同一目录；docx/pdf 由 md 生成，生成物不纳入 Git，源文件必须提交。
- 文档命名建议：`<主题>-v<版本>.md`，日期类文档用 `-YYYYMMDD` 后缀；版本号只升不降。
- 历史手册截图目录（`02-用户与管理员手册/截图素材/`）按版本保留，便于对照旧版手册。
- 安装教程的图片使用相对路径引用 `安装包使用教程-截图/`，移动目录时需同步检查图片引用。
- 文档间引用使用相对路径；跨类别引用写成 `../<类别目录>/<文件名>`。
- 敏感信息（账号、密码、授权文件、密钥）不得写入文档。

## 维护流程

1. 新增或更新文档：先放入对应类别目录，再更新本索引。
2. 涉及交付的教程类文档：修改 md 后重新生成 docx/pdf（pandoc + LibreOffice convert），确保交付件与源文件一致。
3. 涉及版本发布：同步检查 `deploy/offline-package` 与安装教程中的版本号。
4. 文档结构调整后，运行一次链接检查：确认 Markdown 内相对路径的图片、文档引用仍可解析。
