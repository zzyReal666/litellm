# 临时隐藏功能清单

版本 v1.0
日期 2026-11-24
适用 中安云科 AI 安全网关（LiteLLM 中文版）
目的 记录本轮按产品要求临时隐藏的界面入口，后续需要放开时按本文操作

## 一、隐藏清单

| 序号 | 位置 | 隐藏内容 | 说明 |
| --- | --- | --- | --- |
| 1 | 侧边栏「开发者工具」分组 | 整组隐藏，包含：API 参考、AI Hub、缓存（Response Cache）、实验性功能（提示词、API Playground、标签管理、旧版用量） | 导航分组整体不展示 |
| 2 | 访问控制 → 组织 | 隐藏「组织」入口 | 组织功能与数据保留，仅入口隐藏 |
| 3 | 虚拟密钥详情页 | 隐藏「重新生成密钥」按钮 | 密钥的生成/复制/禁用等其他操作保留 |
| 4 | 日志页 | 隐藏「审计日志」标签页 | 请求日志、已删除密钥、已删除团队保留；审计数据与接口保留 |
| 5 | 内部用户页 | 隐藏「批量邀请用户」按钮 | 单个邀请用户保留 |
| 6 | 团队页 | 隐藏「导出 CSV」按钮 | 团队列表、详情与成员管理保留 |
| 7 | 导航 AI 网关 | 隐藏「智能体」入口 | 页面与数据保留，后续完善后放开 |
| 8 | 导航 AI 网关 | 隐藏「MCP 服务器」入口 | 页面与数据保留，后续完善后放开 |
| 9 | 导航 AI 网关 | 隐藏「技能」入口 | 页面与数据保留，后续完善后放开 |
| 10 | 导航 AI 网关 | 隐藏「策略」入口 | 页面与数据保留，后续完善后放开 |
| 11 | 导航 AI 网关 | 隐藏「工具」入口（含搜索工具、向量库、工具策略子项） | 页面与数据保留，后续完善后放开 |
| 12 | 模型与端点-模型详情-编辑 | 隐藏「团队」字段 | 组织、模型访问组等其余字段保留；团队归属仍可通过接口维护 |
| 13 | 导航可观测性 | 隐藏「链路分析」入口 | 页面与数据保留，后续完善后放开 |

以上两项只影响导航入口的展示，不删除页面、接口和数据。直接访问页面 URL 仍可打开；如果后续需要「入口隐藏 + 路由阻断」，需要额外增加路由守卫，属于另一个改动。

## 二、生效范围

- 侧边栏导航（桌面、折叠态）
- 命令面板（`Ctrl+K` 搜索页面与操作）
- 以上两处都通过 `visibleMenuGroups` 生成，隐藏规则只在一个地方维护

## 三、实现位置

唯一开关文件：`ui/litellm-dashboard/src/lib/hiddenProductEntries.ts`

```ts
export const HIDDEN_MENU_GROUP_LABELS: ReadonlySet<string> = new Set(["DEVELOPER TOOLS"]);
export const HIDDEN_MENU_ITEM_KEYS: ReadonlySet<string> = new Set([
  "organizations",
  "agentic",
  "mcp-servers",
  "skills",
  "policies",
  "tools",
  "lens",
]);

export const HIDE_REGENERATE_KEY_BUTTON: boolean = true;

export const HIDE_AUDIT_LOGS_TAB: boolean = true;

export const HIDE_BULK_INVITE_USERS: boolean = true;

export const HIDE_TEAM_EXPORT_CSV: boolean = true;

export const HIDE_MODEL_TEAM_FIELD: boolean = true;
```

- `HIDDEN_MENU_GROUP_LABELS`：按侧边栏分组标签隐藏整组，值是 `leftnav.tsx` 里 `groupLabel` 的原文（英文，用作内部标识）
- `HIDE_REGENERATE_KEY_BUTTON`：为 `true` 时隐藏密钥详情的「重新生成密钥」按钮
- `HIDE_AUDIT_LOGS_TAB`：为 `true` 时隐藏日志页的「审计日志」标签页
- `HIDE_BULK_INVITE_USERS`：为 `true` 时隐藏内部用户页的「批量邀请用户」按钮
- `HIDE_TEAM_EXPORT_CSV`：为 `true` 时隐藏团队页的「导出 CSV」按钮
- `HIDE_MODEL_TEAM_FIELD`：为 `true` 时隐藏模型详情编辑表单中的「团队」字段
- `HIDDEN_MENU_ITEM_KEYS`：按菜单项 `key` 隐藏单项；当前含 `organizations`、`agentic`（智能体）、`mcp-servers`、`skills`、`policies`、`tools`（工具，整组隐藏，子项一并消失）、`lens`（链路分析），值是 `leftnav.tsx` 里 `key` 字段
- 过滤逻辑接在 `visibleMenuGroups` 与 `menuItemIsVisible`，对所有角色生效（管理员同样看不到）
- 回归测试：`ui/litellm-dashboard/src/components/leftnav.hiddenEntries.test.tsx`

## 四、放开步骤

1. 打开 `src/lib/hiddenProductEntries.ts`，删除 `HIDDEN_MENU_GROUP_LABELS` 中的 `"DEVELOPER TOOLS"`、`HIDDEN_MENU_ITEM_KEYS` 中的 `"organizations"`，或把 `HIDE_REGENERATE_KEY_BUTTON`、`HIDE_AUDIT_LOGS_TAB` 改为 `false`；各项可以分别放开。
2. 重新构建前端并部署（流程参照禅道 Bug 处理标准流程：`npm run build` → 镜像叠层 → 部署验证）。
3. 验证三处后回归：
   - 侧边栏对应分组/入口出现，且菜单项可点击；
   - 命令面板搜索到对应页面（如「组织」「API 参考」）；
   - 页面本身可正常打开、数据正常。
4. 更新本文档和验证报告，按版本号出新的安装包。

## 五、回滚

如果放开后需要再次隐藏，把对应值加回 Set 即可，不需要改其他文件。

## 六、注意事项

- 隐藏的只是界面入口，后端接口、数据库表和已有数据不受影响。
- 如果后续新增同类隐藏项，统一加到 `hiddenProductEntries.ts` 并在本文档登记，不要散落在组件里。
- 隐藏规则对所有角色生效；如果将来需要按角色/环境开关，应改为读取 general settings 的配置项，而不是直接写死 Set。
- 菜单项 `key` 与页面路由的对应关系见 `ui/litellm-dashboard/src/components/leftnav.tsx` 的 `menuGroups`（`key`、`page`、`route` 字段）。
