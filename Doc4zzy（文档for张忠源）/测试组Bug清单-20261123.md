## 三、模型端点管理（10）

### 1605 编辑模型：编辑模型，更新时间也没有显示

表现：编辑模型页面看不到创建时间和更新时间，保存修改后也没有任何时间信息变化。

期望：模型详情展示创建时间与更新时间，保存成功后更新时间立即刷新，格式与列表页一致。

### 1590 编辑模型：编辑模型选择团队，保存失败

表现：编辑已部署模型时选择团队后保存，操作失败，团队没有保存成功，界面只给出通用错误。

期望：选择团队后可以正常保存，保存成功后在模型详情和列表里都能看到该团队；失败时提示具体原因。

### 1589 编辑模型：团队选择了，不能删除

表现：模型此前选择过团队，再次编辑时无法把团队清除，保存后团队仍然存在。

期望：编辑时可以选择「无团队」并保存，保存后模型与团队的绑定被移除。

### 1588 添加模型：模型一次添加完成，建议退出到已添加界面或者按钮变成再次添加

表现：模型创建成功后仍停留在添加表单页面，没有成功跳转，也没有明确的「再次添加」入口，用户不确定是否添加成功。

期望：添加成功后自动回到「已部署模型」列表并高亮新模型；或者保留表单但清空内容，按钮变为「再次添加」，并给出成功提示。

### 1587 已部署模型：测试连接和复用凭据，没有返回连接结果

表现：在已部署模型详情里点测试连接，界面没有给出可查看的结果；模型使用已有凭据时同样没有结果，无法判断连接是否成功。

期望：点击后弹出连接结果，展示成功或失败、耗时、失败原因和请求信息（密钥脱敏），并标明本次使用的是哪个凭据。

### 1586 已部署模型：创作者显示未知，日期未知

表现：已部署模型列表的「创建者」列显示 Unknown，「更新时间」列显示暂无，无法判断是谁在什么时候创建或修改的。

期望：数据库中的模型显示创建者与更新时间，通过配置文件定义的模型显示「配置文件定义」，确实缺失时使用明确的中文兜底文案。

### 1585 连接测试结果：添加模型，点测试连接，提示信息需要优化

表现：添加模型页点测试连接，失败时只显示一段笼统的错误信息，缺少错误码、可能原因和排查建议，部分文案仍是英文。

期望：失败提示分结论、建议、详情三部分，中文展示，按 401、404、超时、限流等常见错误给出对应的排查建议。

### 1584 连接测试结果：复制按钮不好使

表现：在连接测试结果里点「复制到剪贴板」，界面提示复制成功，但剪贴板里没有内容。通过 HTTP 地址访问管理界面时必现。

期望：无论 HTTPS 还是 HTTP 访问，点击复制都能把 curl 命令完整写入剪贴板，并给出真实的成功或失败提示。

### 1583 必填项增加必填标识

表现：添加模型、编辑模型的必填字段没有星号或「必填」提示，只有提交后才会报错。

期望：必填字段统一显示必填标识，选填字段标注「可选」；失焦即校验，提交时定位到第一个错误字段。

### 1582 中文化

表现：模型端点管理相关页面仍有英文文案，例如模型编辑里的 Team 标签、连接测试里的 Troubleshooting Details 与 API Request、高级设置里的说明文字、复杂度路由的等级名称等。

期望：模型添加、编辑、连接测试、高级设置等页面的按钮、标签、提示、占位符全部为中文，术语与全站保持一致。

## 四、内部用户管理（10）

### 1613 批量邀请用户：导入信息没有输入预算，默认填充了预算

表现：批量邀请用户时，导入文件里没有填写预算，导入后用户预算被自动填上了默认值，与导入内容不符。

期望：导入数据没有预算时不设置预算，保持为空；只有明确填写预算时才写入，并在导入结果里提示哪些行未填预算。

### 1612 批量邀请用户：上传导入文件，点开启新的批量导入或者取消，一直显示处理中

表现：上传导入文件后，点击「开启新的批量导入」或「取消」按钮，界面一直停留在处理中状态，无法继续操作。

期望：取消或开启新一轮导入后立即结束当前状态，按钮恢复可用，已上传文件的处理结果明确显示成功或失败。

### 1611 批量邀请用户：批量导入失败的提示信息优化

表现：批量导入失败时只给出笼统提示，没有说明失败原因和失败行数，用户不知道如何修正导入文件。

期望：失败提示说明原因（文件格式、字段缺失、重复用户等），给出失败行数与行号，支持导出失败明细。

### 1610 批量邀请用户：换行显示

表现：批量邀请页面部分文案或数据没有换行，内容挤在一起或超出显示区域。

期望：长文案与表格内容正常换行，列宽合理，不出现内容重叠或截断。

### 1609 用户：团队建议显示名称，而不是ID

表现：用户列表或用户详情里，团队信息显示为团队 ID，不便于识别。

期望：团队位置显示团队名称（有别名时显示别名），ID 可作为辅助信息或悬浮提示。

### 1608 邀请用户：邀请成功之后，建议直接退出页面

表现：邀请用户成功之后仍停留在邀请页面，用户需要手动返回。

期望：邀请成功后自动关闭或返回用户列表，并提示邀请结果（成功数量、失败原因）。

### 1607 邀请用户：邀请成功之后，建议增加一个类似设置密钥的地方

表现：邀请用户成功后没有紧接着设置密钥或查看新用户密钥的入口，需要再去用户列表操作。

期望：邀请成功后的结果页提供「设置密钥」或「查看密钥」的操作入口，方便直接完成后续配置。

### 1604 批量邀请：中文化

表现：批量邀请相关页面的按钮、提示和表头存在英文文案。

期望：批量邀请流程全部中文化，术语与用户管理其他页面一致。

### 1603 删除用户：没有自动刷新页面

表现：删除用户后页面列表仍显示已删除的用户，需要手动刷新才能看到结果。

期望：删除成功后列表自动刷新，被删除的用户消失并给出成功提示。

### 1599 中文化

表现：内部用户管理相关页面仍有英文文案，与整体中文界面不一致。

期望：用户列表、用户详情、邀请与批量导入等页面全部中文化。

## 五、虚拟密钥管理（6）

### 1602 重复添加，提示信息优化

表现：添加虚拟密钥时若名称重复，提示信息不够明确，没有指出重复的字段。

期望：重复时明确提示是名称还是其他字段重复，并给出处理建议。

### 1601 重新生成密钥按钮点击无效

表现：在密钥详情或列表点击「重新生成密钥」，按钮没有反应，密钥没有更新。

期望：点击后二次确认，确认后生成新密钥并提示旧密钥立即失效，同时提供复制新密钥的入口。

### 1600 下拉和默认显示统一

表现：密钥页面筛选下拉框的选项与默认展示值不一致，例如默认显示全部但下拉选中的是其他项。

期望：下拉选项、默认值与页面实际展示保持一致，默认状态明确可见。

### 1598 中文化，如果用不到的选项，建议隐藏

表现：密钥页面仍有英文文案，并且存在当前部署用不到的选项（例如某些高级配置），干扰使用。

期望：相关文案全部中文化；当前版本用不到或未启用的选项默认隐藏，需要时再展开。

### 1597 复制按钮不好使

表现：密钥复制按钮点击后提示成功但剪贴板没有内容，通过 HTTP 访问管理界面时必现。

期望：复制按钮在 HTTPS 和 HTTP 下都能正常工作，失败时提示失败原因。

### 1596 创建密钥：增加必填标识（已解决）

表现：创建密钥表单的必填项没有明显标识。

期望：必填项有统一必填标识，提交时逐项校验。此条禅道状态为已解决，待测试组回归确认。

## 七、团队管理（4）

### 1614 添加团队：参数没有具体提示

表现：添加团队时字段填写不符合要求，提示信息笼统，没有说明具体规则。

期望：每个字段给出明确校验提示（长度、格式、必填等），保存失败时定位到具体字段。

表现：团队导出文件包含大量页面未展示的字段，且与页面显示不一致。

### 1580 必填项没有必填标识，并且提示信息需要优化

表现：添加或编辑团队的必填字段没有标识，校验提示不明确。

期望：必填项有统一标识，错误提示说明缺什么、怎么填。

### 1579 输入框的提示信息都中文化

表现：团队管理表单的输入框占位符与提示文字仍是英文。

期望：所有输入框占位符和提示文字中文化，术语与全站一致。

## 八、授权管理（3）

### 1570 授权信息：同一个页面内容重复显示，可以去掉冗余的

表现：授权信息页面重复展示相同内容（例如机器码与产品序列号），信息冗余。

期望：去掉重复项，只展示一份必要信息。

### 1569 授权信息：临时授权和永久授权，授权状态没有区分

表现：临时授权与永久授权的状态展示没有区别，无法直观判断授权类型和剩余期限。

期望：明确展示授权类型（临时/永久），临时授权显示到期时间与剩余天数，永久授权显示「长期有效」。

### 1567 授权信息：建议不显示授权文件及其路径

表现：授权信息页面展示了授权文件的文件名和服务器路径。

期望：隐藏授权文件路径等内部信息，仅展示授权状态、类型、有效期等对用户有意义的内容。
